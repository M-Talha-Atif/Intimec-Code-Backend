API ENDPOINT UPDATED
====================

Before:
  POST /api/v1/entitlements/analytics/kpi
  Body: {"resourceId": "uuid", "tenantId": "tenant"}

After:
  POST /api/v1/entitlements/analytics/kpi
  Header: X-Tenant-ID: tenant-123
  Body: (empty)

Example Request:
  curl -X POST http://localhost:8080/api/v1/entitlements/analytics/kpi \
    -H "X-Tenant-ID: tenant-acme-corp"

Example Response:
  {
    "tenantId": "tenant-acme-corp",
    "totalEntitlements": 250,
    "activeEntitlements": 235,
    "orphanedEntitlements": 8,
    "unclassifiedEntitlements": 12,
    "highRiskEntitlements": 45,
    "averageUsersPerEntitlement": 3.2,
    "timestamp": 1704067200000
  }
